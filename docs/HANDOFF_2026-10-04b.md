## The nine, one by one

1. **Make Alpha's live source a normal git tree.** **Needs Laptop41.** The
   tools already exist and have never been run. On the host:
   ```powershell
   cd C:\services\alpha-tunnel; git checkout main; git pull
   node scripts/publish-alpha.mjs --dir <Alpha root>     # audit: changes nothing
   powershell -ExecutionPolicy Bypass -File scripts\publish-alpha-push.ps1 -AlphaRoot <Alpha root>          # audit again
   powershell -ExecutionPolicy Bypass -File scripts\publish-alpha-push.ps1 -AlphaRoot <Alpha root> -Push    # only after reading it
   ```
   It refuses anything that looks like a credential, pushes to the branch
   `alpha-from-host`, never to `main`, and never forces. Once that branch
   exists, the next session compares it with `alpha-full` and makes one of
   them the real app at the repository root.
2. **Set this repo's default branch to `main`.** **Needs the owner:**
   Settings → General → Default branch. No tool here can change it. Until
   then, `docs/STATUS.md` and Alpha's `AGENTS.md` say to clone with
   `--branch main`, and Alpha's `scripts/tunnel-sync.mjs` refuses any checkout
   that is not at `main`.
3. **CI and one status page.** Done here. `npm test` runs on every PR and on
   every push to `main`. `docs/STATUS.md` lists what is current, what is
   superseded, and what is open. The dated docs stay where they are, because
   the cloud relay and other docs link to them by path. For `vyos88/Alpha`,
   Actions never starts a job (`startup_failure`, zero jobs, even with no
   marketplace actions). That is a settings or billing problem for the owner.
4. **Shadowed routes.** Done (Alpha #39). At startup, `main.py`'s dedup drops
   **189** handlers that a later registration of the same method and path
   shadows. The ownership audit ran after the dedup, so it had never seen one.
   That is how a second `/auth/login` skipped 2FA.
   `tests/test_route_shadow_ratchet.py` now fails on any new one, and the
   baseline list can only shrink. **Not done:** splitting the 39k-line
   `main.py` into one router per hub. The ratchet is what makes that safe to do
   one hub at a time. Each of the 189 is a dead copy that can be deleted.
5. **API contract.** Done (Alpha #39). `tests/test_frontend_api_contract.py`
   checks that every literal path the frontend calls (387 of them) exists as a
   route. It found **two broken buttons**:
   - `/recommendations/debug` (Hubs)
   - `/arduino/elegoo/install-alpha-firmware` (Devices)

   Both are listed as known-missing until someone adds the route or removes
   the call. **Not done:** a generated typed client. The test catches the same
   drift with no new build step.
6. **Access rules.** The concrete risk is fixed (Alpha #39):
   `/audit/events` and `/system/audit-summary`, which hold every sign-in's
   username and IP, are owner-only. **Not done:** replacing the remaining
   inline `role != 'owner'` checks with the `require_owner` dependency.
7. **CSS.** Partly done (Alpha #39). `scripts/css-hygiene.mjs` (PostCSS,
   re-runnable) removed 51 selectors for markup that is no longer rendered.
   **Not done:** moving the nine global sheets to `@layer`. Inside a layer,
   `!important` reverses its precedence, so that move needs a screenshot
   comparison of every deck, not a single edit.
8. **Type.** Done for families. 42 "IBM Plex Sans" rules now use Space Grotesk;
   the app uses Oxanium, Space Grotesk and IBM Plex Mono. For sizes, 129 rules
   under 8px were lifted to 8px. **Not done:** an 11px minimum, which would
   reflow the measured deck layouts.
9. **Light theme and the Network hub.** Done.
   - The Network hub's topology labels render on one line again.
   - atlas-day now changes the page, top bar, nav, deck menu and hub header.
     Content panels keep their dark glass.

   **Not done:** a light treatment for the 197 workspaces, and following
   `prefers-color-scheme`.
