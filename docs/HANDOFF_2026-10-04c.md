# Handoff — 2026-10-04 (c): the visual audit, and the standing backlog

For Alpha, Codex and whoever is at Laptop41. It follows
[`HANDOFF_2026-10-04b.md`](HANDOFF_2026-10-04b.md). The human asked for a
visual audit of every page on mobile and desktop, then for fixes, then for
the remaining work to be handed to Codex and Alpha for good. The last part
is [`BACKLOG.md`](BACKLOG.md): a standing queue, not a one-off list.

## What was audited

Every route the app has: 16 decks, 23 hubs and 198 workspaces. Each was
loaded at 1440x900 and on an Android 412x915 viewport, which is what the
Capacitor Android app shows: 474 page loads. Each got a screenshot, measured
checks, and a look by eye on contact sheets.

The Arduino side was audited as its pages: the Hardware and Devices hubs,
Ports Map, CrowPanel and Elegoo. The firmware itself only runs on a board,
which a cloud session does not have.

| | before | after |
|---|---|---|
| Pages with text squeezed to one character per line | 19 | 0 |
| Crashes, sideways scroll, route-not-found, broken images, failed requests | 0 | 0 |

Three faults showed on nearly every page, and all three are fixed in
[Alpha #41](https://github.com/vyos88/Alpha/pull/41):

1. A full-size gradient over every deck hero, and on phones an oval glow over
   every hub card's text. An accent line had lost its size.
2. The phone shell took a quarter of the screen. Deck header 141 → 71px;
   hub bars 216 → 176px.
3. Text squeezed to slivers in seven places.

## How to see it live

Nothing reaches alpha-ai.uk until the host runs **BACKLOG H1**:
```powershell
cd C:\services\alpha-tunnel; git checkout main; git pull
node scripts/apply-alpha-update.mjs --alpha-root <folder holding Alpha> --apply --restart
```
That one command brings in everything merged today, #36 to #41.

## Re-running the audit

`frontend/scripts/visual-audit.mjs` in Alpha (`alpha-full`). On any machine
that can reach the running app:
```bash
npm i --no-save playwright && npx playwright install chromium
ALPHA_AUDIT_USER=<login> ALPHA_AUDIT_PASSWORD=<password> node scripts/visual-audit.mjs
```
Take the credentials from the environment, never from a file in a repo. It
exits 1 when any page has a problem, and `visual-audit/summary.txt` lists
them by page.

## For Codex and Alpha: the standing work

[`BACKLOG.md`](BACKLOG.md) is the queue. Each item is one PR, claimed through
the coordination tunnel or a draft PR, checked by the suites and the audit,
and deleted from the list in the same PR. Codex's items are reports by
default, because `codex.exec` runs read-only. Anything found and not done
goes back on the list. That is how the work carries on after any one session
ends.
